StoryBot Documentation

Complete guide for using StoryBot with LangChain

🚀 Overview

This StoryBot is a TypeScript-based application that leverages LangChain for document processing and question-answering capabilities. It features a modern web interface with document ingestion, user story retrieval, and intelligent QA functionality.

✨ Features

🔄
Document Ingestion
Upload and process PDF, DOCX, and TXT files with real-time progress tracking and comprehensive error handling.
🔍
User Story Retrieval
Find relevant user stories using semantic search with AI-powered similarity scoring and automated quality assessment.
💬
QA Bot
Interactive chat with context-aware responses, source citations, and support for multiple AI models.

🛠️ Getting Started

Prerequisites

  • Node.js 18.17 or higher
  • Python 3.x
  • MongoDB (for vector storage)

Installation

1. Clone the repository

git clone <repository-url>
cd qa-bot-langchain

2. Install dependencies

npm install

3. Environment Setup

Create a .env file with the following variables:

# AI Model Configuration
OPENAI_API_KEY=your_openai_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
GROQ_API_KEY=your_groq_api_key

# Database Configuration
MONGODB_URI=your_mongodb_connection_string

# Application Settings
PORT=8000
NODE_ENV=development

Running the Application

Quick Start: Run both frontend and backend with a single command
npm run app

Start Services Individually:

npm run backend # Backend API Server (port 8000)
npm run frontend # Frontend UI Server (port 3000)

Development Mode:

npm run dev # Backend with hot reload

📚 Usage Guide

Document Ingestion

  1. Navigate to the Ingestion Tab - Click on "Document Ingestion" in the main interface
  2. Upload Documents - Drag and drop files or click "Browse files" (Supports PDF, DOCX, TXT)
  3. Configure Processing Options:
    • Split Documents: Break large documents into chunks
    • Generate Embeddings: Create vector embeddings for semantic search
    • Store Metadata: Extract and store document metadata
  4. Monitor Progress - Real-time progress bar shows processing status with detailed logs

User Story Retrieval

  1. Access the Retrieval Tab - Switch to "User Story Retrieval"
  2. Enter Your Query - Use natural language (e.g., "user authentication with social media")
  3. Configure Search Parameters:
    • Result Limit: Number of stories to retrieve (1-20)
    • Similarity Threshold: Minimum relevance score
  4. Review Results:
    • Generated Story: AI-created user story based on your query
    • Quality Score: Automated assessment of story quality
    • Relevant Stories: Existing stories ranked by similarity

  • npm run build - Build TypeScript to JavaScript

Model Configuration

The application supports multiple AI providers with automatic fallback:

  • Primary: OpenAI (GPT-4, GPT-3.5-turbo)
  • Secondary: Anthropic (Claude-3, Claude-2)
  • Fallback: Groq (Llama, Mixtral)

🛠️ Troubleshooting

Common Issues

Documents Not Processing:
  • Check file format (PDF, DOCX, TXT supported)
  • Verify file size limits (max 10MB)
  • Ensure stable internet connection for AI model access
Search Not Returning Results:
  • Ensure vector index is created and populated
  • Try more specific query terms
  • Lower similarity threshold for broader results
API Errors:
  • Verify AI provider API keys in environment
  • Check API rate limits
  • Ensure MongoDB is running and accessible

Debug Mode

Enable debug logging:

export NODE_ENV=development
export DEBUG=qa-bot:*
npm run dev
